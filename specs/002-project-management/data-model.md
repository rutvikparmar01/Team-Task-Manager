# Phase 1 Data Model: Project Management

This is a **delta** to the `Project` entity documented in
`specs/001-team-task-management/data-model.md`. `Task` and `TeamMember` are unaffected by this
feature and are not repeated here — see the `001` data model for those.

## Project (updated)

| Field | Type | Rules |
|---|---|---|
| `id` | string (Mongo ObjectId) | Generated by the database |
| `name` | string | Required; trimmed; **3-100 characters after trimming** (FR-002/FR-003/FR-004); **unique case-insensitively across all projects, after trimming** (FR-005) |
| `description` | string | Optional; no length constraint (unchanged from `001`) |
| `createdAt` | ISO date-time | Set on creation; not user-editable (unchanged from `001`) |

**What changed from `001`**: `name` gained a length range (previously only "non-blank") and a
uniqueness constraint (previously explicitly *not* unique — `001`'s spec has been amended to
note this supersession).

**Index**: `{ name: 1 }`, `unique: true`, collation `{ locale: "en", strength: 2 }` (case- and
accent-insensitive comparison). See `research.md` item 2 for why both this index and an
application-level pre-check are required together.

**Relationships**: Unchanged — a Project still has zero or more Tasks.

**Migration note**: This index cannot be created against a collection that already contains a
duplicate (case-insensitive) name. See `research.md` item 3 and `quickstart.md` for the required
one-time cleanup step.
